BIOBOOST WEBSITE — VERSI RESPONSIF

Cara membuka:
1. Ekstrak ZIP ke folder.
2. Buka folder bioboost-website di Visual Studio Code (File > Open Folder).
3. Pastikan index.html, style.css, script.js, dan folder assets berada dalam satu folder.
4. Klik kanan index.html > Open with Live Server (pastikan ekstensi Live Server terpasang), atau buka index.html langsung di browser.

Fitur:
- Navigasi menampilkan satu halaman/bagian setiap kali menu diklik.
- Tampilan responsif untuk laptop dan ponsel.
- Tiga varian produk dengan ilustrasi kemasan dan deskripsi.
- Kalkulator dosis berdasarkan angka pada dokumen rencana bisnis.
- Himbauan dan larangan sesuai dokumen pengguna.
- Kontak telepon, email, dan alamat.

PENTING:
Angka dosis disalin dari dokumen rencana bisnis, belum merupakan rekomendasi agronomi yang tervalidasi. Dokumen memuat perbedaan dosis tanaman hias: varian spray disebut siap pakai tanpa pengenceran, sedangkan bagian himbauan menyebut 10 ml biang per 2 liter air. Konfirmasikan sebelum penggunaan atau publikasi sebagai instruksi resmi. Klaim manfaat dan keamanan produk perlu pengujian.
